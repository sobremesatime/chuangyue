# api · 对外契约

本目录存放所有对外契约，是前后端、以及各服务之间的唯一约定来源。

| 目录 | 内容 | 消费方 |
| --- | --- | --- |
| `openapi/` | 前后端 HTTP 接口契约（OpenAPI 3.0） | 前端生成 TS 类型、后端据此实现接口 |
| `proto/` | 服务间 gRPC 契约（Protobuf） | 各微服务生成客户端与服务端代码 |

## 约定

- **契约先行**：先改契约、再改实现；契约变更必须走代码评审。
- **版本化**：`proto/<service>/v1/` 按服务与版本分目录；OpenAPI 文件名带版本号 `chuangyue.v1.yaml`。
- **生成物不入库**：由 `make proto` / `make openapi` 生成的代码不提交。
- **雪花 ID 以字符串传输**：64 位 ID 超出 JavaScript 安全整数上限，按 JSON 数字传输会在前端静默丢精度（同毫秒内相邻的 ID 会塌缩成同一个值）。凡承载雪花 ID 的字段——响应体与路径参数——一律声明为 `string`；`category_id`、各类计数这类小整数不受此限。
